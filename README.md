# Zeus-Protocol
ZEUS Protocol is a personal wellness tracker that runs as one self-contained HTML file — no build step, no dependencies, no backend.

Agenda merges routines, supplement blocks and calendar events into one timeline, with a live eating-window countdown
Routines support optional items you switch on per day, weekday scheduling and streak counters
Supplements are grouped into timed blocks with doses
Calendar subscribes to iCal feeds through a Cloudflare Worker proxy, with month and day views
Bio Analysis reads biomarkers from lab PDFs and compares them against previous panels

All data stays in the browser's local storage on your device.
